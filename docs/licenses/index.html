SAOLA data sources and licences

SAOLA country packs summarize wildlife occurrences. A map marker can represent multiple source records and is an approximate display location, not proof of an individual sighting. Source coordinates and weighted counts are retained in the pack for audit.

Occurrence datasets

  • eBird Observation Dataset — CC BY 4.0
  • Observation.org, Nature data from around the World — CC BY-NC 4.0
  • iNaturalist Research-grade Observations — dataset CC BY-NC 4.0; some individual records have more permissive licences

These datasets are accessed through GBIF. SAOLA is free, without advertising, subscriptions or in-app purchases. CC BY-NC material cannot be reused commercially without separate permission. Pack-specific GBIF download DOIs document the exact extracts.

Mapping and species references

  • GRIIS national checklists (CC BY 4.0) determine confirmed introduced species for each country. Country lists can be incomplete; ambiguous status remains visible.
  • ESA WorldCover 2021 (CC BY 4.0) informs approximate display placement within a source grid cell. Habitat suitability is inferred and does not confirm a sighting.
  • Natural Earth country boundaries (public domain) keep inferred positions inside the listed country.
  • GeoNames place names (CC BY 4.0); nearby names label route areas, not park boundaries.
  • OpenStreetMap contributors map and road data (ODbL); FOSSGIS provides beta routing.
  • Leaflet map software (BSD-2-Clause).
  • Bird range labels use IOC World Bird List and other cited range references; mammal names use Mammal Diversity Database where available.
